# aliartukov.github.io

Персональный сайт-резюме Ali Artukov, Head of Java Development в Click: https://aliartukov.github.io/

## Устройство

Статический сайт без сборки и зависимостей:

| Файл | Назначение |
|---|---|
| `index.html` | Весь контент страницы |
| `assets/style.css` | Стили: светлая и тёмная темы, адаптив, версия для печати |
| `assets/main.js` | Переключатель темы, мобильное меню, подсветка разделов, автоподсчёт стажа |
| `assets/favicon.svg` | Иконка сайта |

Стаж («5+ лет», «4 года 7 месяцев» и т. п.) считается в браузере от дат в атрибутах
`data-years-since` / `data-duration-since`, так что сайт не устаревает сам по себе.

Кнопка «Резюме в PDF» открывает печать: print-стили превращают страницу в одноколоночное резюме,
которое можно сохранить в PDF.

## Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация

GitHub Pages публикует ветку `main` из корня репозитория, после push изменения появляются через минуту-две.
