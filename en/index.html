01 / About

An engineer who grew into leading the Java practice

I have been writing Java for six years, most of them at Click, where I went from Java developer to Head of Java Development.

One of my key achievements is building the Java practice almost from scratch. Instead of extending the PHP and Node.js legacy, we designed and launched a number of microservices, including a payment fiscalization system and an integration for processing Visa/Mastercard payments.

My management experience grew with the scope of work: team lead of 5 developers, then head of the Java guild, and now I am responsible for every Java developer in the company, from hiring to architecture decisions and engineering standards. I pay special attention to standardizing projects: I see it as the foundation for growing teams without losing quality.

Goal Grow towards a CTO role in a technology company.

02 / Highlights

What I have delivered

Java practice from scratch

Instead of extending the PHP and Node.js legacy, we designed and launched a set of microservices at Click.

Payment fiscalization (OFD)

A service that issues fiscal online receipts for payments made through CLICK: Java 17, Spring, ActiveMQ Artemis, PostgreSQL, Vault.

First on the market: fuel station receipts

We were the first payment service to fiscalize receipts for fuel stations, including the volume of fuel sold. This helped retain several major partners with multi-billion turnovers.

Visa / Mastercard payments

An integration for processing international card payments, plus gateways to CyberSource, PayGine, RocketGate, HUMO, soliq.uz, Tasnif and the Prosecutor General's Office.

A single Java engineering standard

I am rolling out a common standard for developing, maintaining and accepting Java projects, and review ongoing and finished projects to keep best practices and avoid repeating past mistakes.

AI in engineering and management

Experiments with Spec-Driven Development in Claude Code, AI-assisted documentation of tasks and backlog. I run Java guild sessions on hands-on AI experience.
